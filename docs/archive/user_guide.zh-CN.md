### 4️⃣ 系统设置 ⚙️

**功能**: 配置系统参数

#### 基础设置

**📊 采样率 (ms)**
- 默认值: 1000
- 范围: 100-10000
- 说明: 数据采集间隔时间

**🔺 高压警报阈值 (hPa)**
- 默认值: 95.0
- 说明: 超过此值触发红色警报

**🔻 低压警报阈值 (hPa)**
- 默认值: 5.0
- 说明: 低于此值触发黄色警报

**💾 数据保留数量**
- 默认值: 1000
- 说明: 缓冲区最大容量
- 超出部分自动转入历史

**📈 图表更新率**
- 默认值: 10
- 说明: 每N次采样更新一次界面

**🔄 自动保存**
- 默认值: False
- 说明: 定时自动保存数据

**🔊 启用声音**
- 默认值: True
- 说明: 警报时播放声音

**🎨 主题**
- 选项: dark / light
- 当前仅支持 dark

## ❓ 常见问题

### Q1: 程序无法启动？
**A**: 检查以下几点
1. Python是否已安装 (需要3.7+)
2. 依赖包是否已安装
3. 运行 `install_dependencies.py`

### Q2: 图表不显示？
**A**: 可能原因
1. matplotlib未安装
2. 数据缓冲区为空
3. 等待几秒让数据累积

### Q3: 导出数据失败？
**A**: 检查
1. 桌面路径是否可写
2. openpyxl是否已安装
3. 是否有数据可导出

### Q4: 设置不生效？
**A**: 
1. 确保点击了"保存设置"
2. 重启程序生效
3. 检查 settings.json 是否存在

### Q5: 内存占用过高？
**A**: 调整设置
1. 减少"数据保留数量"
2. 增加"图表更新率"
3. 定期导出并刷新数据

## 💡 技巧和窍门

### 高效使用

1. **快速查看趋势**
   - 主界面曲线图默认显示最近100点
   - 适合快速观察短期变化

2. **深入分析**
   - 使用"数据分析"查看统计指标
   - 箱线图识别异常值

3. **长期监控**
   - 设置合适的数据保留数量
   - 定期导出数据备份
   - 使用历史记录功能回溯

4. **性能优化**
   - 采样率设置为1000ms足够大多数场景
   - 图表更新率10-20最佳平衡
   - 数据保留500-2000条

### 数据管理

1. **定期备份**
   - 每天导出一次数据
   - 文件自动带时间戳，不会覆盖

2. **历史数据**
   - 历史记录自动保存在内存中
   - 程序重启后清空
   - 重要数据及时导出

3. **异常检测**
   - 观察状态指示器
   - 🟢 正常 / ⚠️ 警报
   - 查看数据分析中的异常点数

### 界面技巧

1. **窗口管理**
   - 所有子窗口独立
   - 可同时打开多个功能窗口
   - 主窗口不影响子窗口

2. **数据卡片**
   - 颜色编码便于识别
   - 红色=电流，青色=气压
   - 实时更新，无需刷新

3. **状态栏**
   - 左侧状态点显示运行状态
   - 采样计数实时更新
   - 观察是否正常采集

## 🔧 高级功能

### 自定义配置

编辑 `settings.json` 文件:
```json
{
    "sampling_rate": 1000,
    "alert_threshold_high": 95.0,
    "alert_threshold_low": 5.0,
    "data_retention": 1000,
    "auto_save": false,
    "theme": "dark",
    "enable_sound": true,
    "chart_update_rate": 10
}
```

### 数据格式

导出的Excel文件格式:
```
timestamp              | current  | pressure
2025-11-13 10:30:45.123| 12.3456  | 48.22
2025-11-13 10:30:46.124| 11.9876  | 50.77
...
```

### 扩展开发

程序采用模块化设计，易于扩展:
- 修改 `generate_fake_data()` 接入真实传感器
- 添加新的统计指标到 `show_analysis()`
- 自定义配色在 `setup_styles()`
- 增加功能按钮在 `create_interface()`
