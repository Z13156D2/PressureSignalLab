📝 使用建议:

1. Windows 10/11 原生支持彩色 Emoji
2. 需要安装 Segoe UI Emoji 字体（通常预装）
3. 如显示为黑白方块，请更新系统字体
4. 在代码中直接使用 Unicode 字符即可

🎨 配色与图标搭配建议:

红色系图标 (🔴⚠️🔥) → 警告、错误、紧急
绿色系图标 (🟢✅💚) → 正常、成功、安全  
蓝色系图标 (📊📈💙) → 数据、信息、中性
黄色系图标 (⚡💛⚠️) → 警告、注意、快速
